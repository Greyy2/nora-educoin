# D1 — OKX ecosystem reality (round 1, researcher 1)

Accessed: 2026-09-28. Budget used: ~23 tool calls, 14 distinct sources.
Notes on method: "search-summary" means the claim came from a WebSearch result summary without a full-page fetch; treat those as one notch weaker. npm/GitHub figures were pulled live from api.npmjs.org and api.github.com on the access date.

## (a) Findings

### What "OKX AI" is (feature / launch)
- OKX added a native AI layer to OnchainOS on 2026-03-03. Agents can manage wallets, pay, trade and read markets across 60+ chains and 500+ DEX sources. Access is through natural-language "AI Skills", MCP and REST APIs. | https://www.coindesk.com/tech/2026/03/03/okx-jumps-into-ai-agent-race-with-new-onchainos-toolkit | CoinDesk | 2026-03-03 | accessed 2026-09-28 | high | launch
- OKX says the OnchainOS infra behind the AI layer handles 1.2B API calls per day and about $300M in trading volume per day. This covers the whole infra, not agents only, and the number is not audited. | https://www.coindesk.com/tech/2026/03/03/okx-jumps-into-ai-agent-race-with-new-onchainos-toolkit | CoinDesk (citing OKX) | 2026-03-03 | accessed 2026-09-28 | med | metric
- OKX says OnchainOS is "backed by the same infra trusted by 12M+ monthly @wallet users". | https://x.com/okx/status/2028757415974306005 | OKX (X post) | ~2026-03-03 | accessed 2026-09-28 | med (search-summary, self-reported) | metric
- "OKX AI" is a marketplace launched on 2026-06-30. It has two parts. In the Agent Marketplace, builders list agents with services and prices. In the Task Marketplace, agents post work and pay on delivery. Settlement is in USDT or USDG, either through escrow or instant pay-per-call. | https://www.theblock.co/post/406704/okx-ai-unveils-marketplace-for-agents-to-find-work-and-get-paid-in-stablecoins | The Block | 2026-06-30 | accessed 2026-09-28 | high | launch
- The official OKX Learn page describes OKX AI as "a marketplace where AI agents can discover work, collaborate, transact, and build reputation onchain". It is built on Agentic Wallet (one onchain identity), Agent Identity (reputation) and the Agent Payments Protocol. Supported clients are Claude Code, Codex, Hermes and OpenClaw. Disputes go to staked evaluator networks. | https://www.okx.com/en-us/learn/okx-ai | OKX (primary) | 2026-07-01 | accessed 2026-09-28 | high | feature
- The marketplace went public after a closed beta with 50 early AI service providers. No OKX account is required, and access is through Onchain OS. | https://techcrunch.com/2026/06/30/crypto-exchange-okx-wants-ai-agents-to-hire-and-pay-each-other/ | TechCrunch | 2026-06-30 | accessed 2026-09-28 | high | launch
- okx.ai has three roles: User (posts tasks with a budget and deadline), Agent Service Provider (ASP) and Evaluator (stakes OKB to resolve disputes). Payments settle on X Layer in stablecoins. | https://www.okx.ai/ | OKX (primary) | undated, live page | accessed 2026-09-28 | high | feature
- ASPs choose one of two modes. A2A is escrow on X Layer, with a negotiated or fixed price per task, released when the user approves. A2MCP is a standardized MCP/API service with a fixed price per call, served either free or as an x402 paid endpoint that settles in real time. Onboarding requires an agent client, Onchain OS and an Agentic Wallet login. OKX reviews submissions "within 24 hours". An A2A dispute evaluation needs a 5% bounty deposit, refunded if the dispute succeeds. | https://www.okx.ai/tutorial/asp | OKX (primary) | undated, live page | accessed 2026-09-28 | high | feature/pricing
- OKX announced the Agent Payments Protocol (APP) on about 2026-05-03. It is an open standard covering quotes, negotiation, escrow, usage metering, settlement and disputes. It is positioned against Coinbase x402 and Stripe's Machine Payments Protocol. It runs on X Layer with "none or low" gas, supports multiple chains, and uses a TEE-secured agentic wallet across 20+ chains. | https://www.digitaltoday.co.kr/en/view/52581/okx-unveils-agent-payments-protocol-app-to-rival-coinbase-x402-and-stripe | Digital Today (KR) | 2026-05-03 | accessed 2026-09-28 | med | launch
- Onchain OS docs include an x402 "Payments" module: HTTP-native payment for buyer and seller roles, usable either through agent conversation or Open API. OKX publishes a Go x402 package at github.com/okx/payments. | https://web3.okx.com/onchainos/dev-docs/payments/x402-introduction ; https://pkg.go.dev/github.com/okx/payments/go/x402 | OKX (primary) | undated | accessed 2026-09-28 | med (search-summary) | feature
- OKX Wallet supports gas-free USDT/USDC transfers on X Layer, with the relay sponsored under x402. | https://onekey.so/blog/ecosystem/okx-wallet-now-supports-0-gas-usdt-and-usdc-transfers-on-x-layer/ | OneKey blog (third-party) | undated | accessed 2026-09-28 | low (search-summary, secondary) | feature
- Agent Trade Kit is OKX's open-source, local MCP server plus CLI for CEX trading: spot, swap, futures, options and grid bots. Keys stay local in ~/.okx/config.toml and signing happens locally. The current install is `npm install -g @okx_ai/okx-trade-mcp @okx_ai/okx-trade-cli`. | https://github.com/okx/agent-trade-kit | OKX GitHub (primary) | repo created 2026-03-03, pushed 2026-09-23 | accessed 2026-09-28 | high | feature
- The onchainos-skills repo provides agent skills for wallet, token discovery, market data, DEX swap and broadcast. | https://github.com/okx/onchainos-skills | OKX GitHub (primary) | created 2026-02-28, pushed 2026-09-28 | accessed 2026-09-28 | high | feature
