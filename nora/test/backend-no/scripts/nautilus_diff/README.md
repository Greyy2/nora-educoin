# Cross-engine differential test: Nora vs NautilusTrader (2.0.0rc6)
Same bars + precomputed EMA-cross signals -> Nora single kernel engine (`SlotDriver` for one symbol, self-checked == `RefPositionTracker`; `KernelBook` + admission trace for the S8 portfolio; shared code in `step_common.py`) and a Nautilus `BacktestEngine` (L1 bar execution, NETTING/MARGIN). Results and verdict: `REPORT.md`.
1. `cd nora; PYTHONDONTWRITEBYTECODE=1 ops/run_limited.sh --no-lock -- test/scripts/nautilus_diff/export_data.py` (writes `out/`, not committed), then `.../run_nora.py [ohlc|adaptive]` (intrabar_path; adaptive writes `*_adaptive.json`)
2. Nautilus venv (`uv venv ~/.venvs/nautilus --python 3.14; uv pip install --pre nautilus_trader pandas pyarrow`): `systemd-run --user --scope --slice=nora.slice -p MemoryMax=4G ~/.venvs/nautilus/bin/python -I test/scripts/nautilus_diff/run_nautilus.py fine|okx [0|1=adaptive H/L order] [datasets] [stages]`
3. `~/.venvs/nora/bin/python test/scripts/nautilus_diff/compare.py fine|okx [_adaptive]` -> markdown table + `results_<inst><suffix>.json`
4. S9 (P12 part C, multi-frame: 1m execution + 1D signal, 2 symbols, max_positions=1; separate files `s9_*.py`, results in `EXT_REPORT.md` section S9):
   `s9_export_data.py` (nora venv, builds `out/s9/data_root` + csv) -> `s9_run_nora.py [stages|all] [signal_mode]` (real PortfolioEngine) -> Nautilus venv `s9_run_nautilus.py [stages|all]` -> `s9_compare.py [stages|all]` (writes `s9_results.json`, exit 1 on mismatch) -> `check_baseline.py` (covers `out/s9/nora_*.json` + `s9_results.json`). Re-run after any engine change.
5. S10 (exit mechanics: ATR-unit SL/TP, trailing, timeout; 1h/4h signal over 1m, files `s10_*.py`, section S10 of `EXT_REPORT.md`): `s10_export_data.py` (nora venv via `ops/run_limited.sh`) -> `s10_run_nora.py [stages|all]` -> Nautilus venv `s10_run_nautilus.py [stages|all]` (systemd-run, MemoryMax=6G) -> `s10_compare.py [stages|all]` (writes `s10_results.json`, exit 1 on mismatch) -> `check_baseline.py` (covers `out/s10/nora_*.json` + `s10_results.json`).
6. S11 (cooldown > 0, DCA ladder, funding; 1h signal over 1m, 2 symbols, files `s11_*.py`, section S11 of `EXT_REPORT.md`): `s11_export_data.py` (nora venv via `ops/run_limited.sh`; builds `out/s11/data_root` incl. `funding.pkl`) -> `s11_run_nora.py [stages|all]` -> Nautilus venv `systemd-run --user --scope --slice=nora.slice -p MemoryMax=6G ~/.venvs/nautilus/bin/python -I test/scripts/nautilus_diff/s11_run_nautilus.py [stages|all]` -> `s11_compare.py [stages|all]` (fill-by-fill, writes `s11_results.json`, exit 1 on mismatch) -> `check_baseline.py`. Nautilus has no funding cash flow in a bar backtest: the harness applies it as a shadow ledger in the strategy (see EXT_REPORT S11).
