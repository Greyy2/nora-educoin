## Traceability and acceptance gates

Status meanings:
- **GAP**: code inspected and does not currently satisfy the request.
- **UNVERIFIED**: relevant surface exists, but the requested behavior has not been proven end-to-end.
- **IDENTIFIED**: request and relevant surface are mapped; implementation and acceptance still need verification.
- **PRIOR PASS**: a pre-existing system gate was verified; this does not imply the new UX is accepted.

Each row must be closed with evidence (focused test and, where applicable, browser journey). A build-only pass is insufficient.
